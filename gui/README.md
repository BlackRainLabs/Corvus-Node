# GUI tree (development)

This directory is the **GUI team** workspace. The product is **Corvus-Node**. `corvus` is the operator CLI.

- Runtime shipped to operators: `corvus_gui/` (splash). GitHub Release wheel and install tarball include **only** that package.
- This README, `REQUESTS.md`, and Cursor rules stay in git. They are not in the operator tarball.

Read [docs/gui/AVAILABLE.md](../docs/gui/AVAILABLE.md) before calling Node. File needs in [REQUESTS.md](REQUESTS.md). Do not edit Node, guest, or packaging.

`corvus gui` launches the splash. It does not talk to Node in this version.
